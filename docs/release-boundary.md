# 合并边界

这个分支可以作为 GitHub 分支继续工程化；合入 GitCode `main` 前保留当前官方评分骨架，并完成以下检查：

1. 比较合并前后 `user_agent.py` 与 `implementations/` 的默认行为和请求上限。
2. 在干净 Python 环境安装 `requirements.txt`，验证根入口导入、最小 `solve()` 和 JSON 序列化。
3. 运行默认测试和 Demo 合同测试。
4. 确认没有题集、答案库、凭证、模型 raw 或本地运行产物进入 Git。
5. 将新增模块作为独立变量记录；没有独立能力证据时保持默认关闭。

本分支的工程演示证据不自动等同于官方评测能力证据，也不自动授权推送或合并。
